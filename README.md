# Agent 协作工作流体系

> 一套结构化多 AI Agent 协作方案——7 角色 + 4 阶段工作流，用于 vibecoding 场景下的 AI 辅助编程。

## 架构总览

```
┌─────────────┐     调度/汇报       ┌─────────────────┐
│  用户(Owner) │◀──────────────────│   主 Agent      │
│  需求发起者   │     沟通           │   (Leader)      │
│  最终决策者   │                    │  唯一与用户沟通   │
└─────────────┘                    └────────┬────────┘
                                            │ 调度
              ┌──────────────────────────────┼──────────────────────────────┐
              ▼                              ▼                              ▼
     ┌──────────────────┐          ┌──────────────────┐          ┌──────────────────┐
     │   批复角色        │          │   文档维护角色    │          │   实施角色        │
     │  (Approver)      │          │  (DocKeeper)     │          │  (Worker)        │
     │  走流程而非做评判  │          │  统一维护文档     │          │  只负责实施       │
     │  结论由流程产出    │          │                   │          │  不具有调度能力    │
     └──────────────────┘          └──────────────────┘          └────────┬─────────┘
                                                                         │ 完成后
                                                                         ▼
                                                               ┌──────────────────┐
                                                               │  内容审查角色    │
                                                               │  (Reviewer)      │
                                                               │  审查代码/方案   │
                                                               └────────┬─────────┘
                                                                         │
                                                               ┌──────────────────┐
                                                               │  测试角色        │
                                                               │  (Tester)        │
                                                               │  编写并运行测试   │
                                                               └────────┬─────────┘
                                                                         │
                                                                         ▼
                                                               批复角色审视验收结论
```

## 7 角色速览

| 角色 | 职责 | 边界 |
|------|------|------|
| **主 Agent (Leader)** | 需求理解、任务拆解、调度、把控、汇报 | 不写代码、不写文档、不写测试 |
| **批复角色 (Approver)** | 走流程做评判：提取→对照→产出→通过/不通过 | 只有通过/不通过两种结果 |
| **实施角色 (Worker)** | 实施具体工作（代码/配置/调试） | 只负责实施，不具有调度能力 |
| **内容审查角色 (Reviewer)** | 审查代码/方案/文档质量 | 产出可操作的修改意见 |
| **测试角色 (Tester)** | 编写并运行测试 | 产出测试报告 |
| **文档维护角色 (DocKeeper)** | 统一维护项目文档 | 唯一负责写入文档 |
| **用户 (Owner)** | 需求发起、决策、验收 | 最终决定权 |

## 四阶段工作流

```
用户需求 → [需求讨论] ───批复通过？───→ [任务规划] ───批复通过？───→ [实施调度] ───批复通过？───→ [总结报告]
                │ 否                        │ 否                        │ 否
                └── 修正需求 ←──┘           └── 修正规划 ←──┘           └── 修正实施 ←──┘
```

## 目录结构

```
├── agent.md              ← 主 Agent 入口（加载此文件启动完整工作流）
├── CLAUDE.md             ← Claude Code 项目指南
├── README.md             ← 本文件
├── CHANGELOG.md          ← 版本变更记录
├── my.md                 ← 原始设计（只读）
├── make.md               ← 核心规范文档（持续维护）
├── SOUL.md               ← 主 Agent 人格定义
├── USER.md               ← 用户画像
├── skills/               ← 角色技能定义
│   ├── approval.md       ← 批复角色（流程驱动）
│   ├── reviewer.md       ← 内容审查角色
│   ├── testing.md        ← 测试角色
│   ├── doc-keeper.md     ← 文档维护角色
│   └── memory.md         ← 记忆管理
├── hooks/                ← 工作流生命周期钩子（结构预留）
├── plugins/              ← MCP 工具与扩展配置（结构预留）
├── memory/               ← 持久知识与活动日志
├── project/.project/     ← 项目文档模板
└── templates/            ← 其他模板
```

## 快速开始

### 方式一：在新项目中使用
```bash
# 将此仓库复制到目标项目
cp -r agent/ /path/to/your/project/

# 在 Claude Code 中打开目标项目
# 加载 agent.md 启动工作流
```

### 方式二：通过 CLAUDE.md 引用
在目标项目根目录的 `CLAUDE.md` 中添加：
```markdown
## Agent 工作流
本项目的 Agent 协作工作流定义在 `agent/` 目录中。
启动方式：加载 `agent/agent.md`。
```

### 方式三：独立 Skill 加载
在任意 Claude Code 会话中，通过 `/skill` 加载单个角色 skill：
```
/skill skills/approval.md   # 让批复角色审视产出
/skill skills/reviewer.md   # 审查代码质量
/skill skills/testing.md    # 执行测试
/skill skills/doc-keeper.md # 更新文档
/skill skills/memory.md     # 管理记忆
```

## 与 Claude Code 配合

| 场景 | 操作 |
|------|------|
| 启动完整工作流 | 加载 `agent.md` 或说"启动 agent 工作流" |
| 调用某个角色 | 加载对应的 `skills/` 文件 |
| 新项目初始化 | 将本仓库复制到目标项目根目录 |
| 查阅完整规范 | 阅读 `make.md`（权威来源） |
