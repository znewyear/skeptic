# Hook: 实施前检查

## 触发条件
主 Agent 即将调度实施角色执行任务之前。

## 执行步骤

1. 确认实施所需的环境工具（Node/python/git 等）可用
2. 确认任务依赖的前置条件已满足（接口定义完成、数据库已创建等）
3. 确认实施角色所需的上下文完整（需求文档、经验文档可读）
4. 产出前置条件检查结果

## 输出格式

```
## 前置条件检查
| 检查项 | 状态(✅/❌) | 说明 |
|--------|-----------|------|
```

## 回退条件
若存在 ❌ 项，主 Agent 应先处理前置条件再调度实施。
