# Hook: 需求批复前预检查

## 触发条件
主 Agent 即将调度批复角色审视需求理解之前。

## 执行步骤

1. 从用户原始需求中提取所有关键词和功能点
2. 从当前需求理解中提取对应项
3. 对比两者，标记缺失项和多余项
4. 产出预检查结果

## 输出格式

```
## 预检查清单
| 用户原词 | 理解对应项 | 是否覆盖(✅/❌) |
|---------|-----------|---------------|
```

## 回退条件
若预检查发现大量缺失（❌ 项超过 50%），主 Agent 应先修正需求理解再进入批复环节。
